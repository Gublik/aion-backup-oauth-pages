AION Backup — statické informační stránky pro Google OAuth.

Obsah: index.html (domovská stránka), privacy.html (zásady ochrany dat),
terms.html (podmínky používání). Žádné přístupové údaje ani soukromá data.

1) Na GitHubu vytvořte nový VEŘEJNÝ repozitář aion-backup-oauth-pages.
2) Rozbalte ZIP a do kořenového adresáře repozitáře nahrajte tři HTML soubory.
   README.txt publikovat nemusíte.
3) Settings > Pages > Build and deployment > Deploy from a branch,
   Branch main, Folder /(root), Save.
4) Otevřete a zkontrolujte skutečné veřejné adresy:
   https://GITHUB_UZIVATEL.github.io/aion-backup-oauth-pages/
   https://GITHUB_UZIVATEL.github.io/aion-backup-oauth-pages/privacy.html
   https://GITHUB_UZIVATEL.github.io/aion-backup-oauth-pages/terms.html
5) Teprve pak je vložte do Google Auth Platform > Branding.
   Authorized domains: zpravidla GITHUB_UZIVATEL.github.io.
   Pokud Google odmítne doménu nebo vyžaduje ověření vlastnictví,
   nezadávejte náhodnou jinou doménu; řešte přes Google Search Console.

Vyžaduje skutečný GitHub uživatelský účet a veřejný přístup k vytvořené stránce.
Pozn.: Google pravidla a způsob ověření domény se mohou měnit.
